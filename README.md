# Chakri Finder (BD Job Finder)

A free job finder for Bangladesh government, private and remote international jobs, with a resume builder, certificate store and application tracker.

- App: https://minhaz-eee.github.io/BD-JOB-FINDER/
- Jobs are collected automatically every 6 hours by GitHub Actions (`scripts/collect.py`).
- Job sources are listed in `scripts/sources.json`.
- Personal data (resume, passwords, certificates) is stored only in the phone's browser, never in this repository.
